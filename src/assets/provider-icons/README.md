# Logos des fournisseurs IA

Fichiers `.svg` repris tels quels du paquet npm `@lobehub/icons-static-svg` version 1.102.0
(dépôt `github.com/lobehub/lobe-icons`), sous licence MIT d'après son `package.json`.

Exception : `openrouter.svg` vient du dossier `Kiro v4.0/images` du mainteneur, même format que le paquet
mais licence non indiquée : le logo du paquet est illisible à 18 px.

Les logos restent des marques de leurs sociétés : ils servent seulement à désigner le service
que le pilote choisit, sans affiliation.

Sans logo dans ce paquet : OVHcloud et LLM7 (pastille avec l'initiale).
